"nodemon": "^3.1.14" in package.json means:

^ (caret) → allow compatible updates

✅ Can update to 3.1.15, 3.2.0 (minor/patch updates)
❌ Will not update to 4.0.0 (major version change)

3 (Major) → Big changes. May include breaking changes (old code may not work).
1 (Minor) → New features added, but should remain backward compatible.
14 (Patch) → Bug fixes, small improvements, security fixes.
